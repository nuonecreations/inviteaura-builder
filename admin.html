📌 Step 1 — GitHub Token එකක් හදන්න (1 minute, එක පාරක් විතරයි)

🔑 1. GitHub Token Page එකට යන්න (Click කරන්න)

එහෙම නැත්නම්: GitHub → profile photo (top-right) → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token

  1. Token name: InviteAura-Publish කියලා දාන්න (නමක් විතරයි).
  2. Expiration: 90 days හෝ No expiration තෝරන්න.
  3. Repository access: Only select repositories තෝරලා → inviteaura-builder කියන එක tick කරන්න. (All repositories එපා — මෙය විතරක්)
  4. Permissions → Repository permissions (arrow එක click කරලා expand කරන්න) → ලැයිස්තුවේ උඩම තියෙන Contents එක හොයන්න. ⚠️ ලැයිස්තුව දිගයි — Repository creation / license policy / security advisories කියලා ඔයා දැක්කේ ඒ ලැයිස්තුවේ පහළ ටික. Contents තියෙන්නේ ඊට උඩ: Actions → Administration → Code quality → Contents → Deployments… ("C" අකුරෙන් පටන් ගන්න එක) — උඩට scroll කරන්න. එතන dropdown එකෙන් Read and write තෝරන්න. වෙනත් permission (Repository creation ආදිය) වලට අත තියන්න එපා — ඒවා ඕනෑ නෑ.
  5. පහළම තියෙන Generate token (green) button එක ඔබන්න.
  6. එන github_pat_… token එක copy කරගන්න. (එක පාරක් විතරයි පෙන්වන්නේ — දැන්ම copy කරන්න!)

🔀 Option B — Fine-grained එක අපහසු නම් Classic Token එකක් (එකත් වැඩ කරනවා)

Permissions ලැයිස්තුව තවම හොයාගන්න බෑ නම් මේක කරන්න: Classic Token Page → Note: InviteAura → Scope: repo (වැඩි ටිකක් සහිත) එක tick කරන්න → Generate → එන ghp_… එක මෙතන paste කරන්න. මේකත් එකම විදිහට වැඩ කරනවා.

📌 Step 2 — Token එක මෙතන Paste කරන්න

✅ "Connected" කියලා එනවා නම් සූදානම්. එහෙම නැත්නම් පහළ troubleshooting එක බලන්න.

📌 Step 3 — හැමදාම: Save Wedding ඔබන්න

  1. ඉහළ form එකේ නම, දිනය, photo, events පුරවන්න.
  2. උඩ තියෙන 💾 Save Wedding button එක ඔබන්න.
  3. File එක GitHub repo එකේ weddings/<slug>.json එකට auto push වෙනවා → commit link එකක් පෙන්වනවා.
  4. ~1 minute වලින් live: https://nuonecreations.github.io/inviteaura-builder/?wedding=<slug>
❓ Problem එකක් ආවොත්? (Troubleshooting)
  • 401 / Bad credentials → Token එක වැරදි නැත්තම් expire වෙලා. අලුත් token එකක් හදලා paste කරන්න.
  • 404 Not Found → Repo නම වැරදි, නැත්තම් token එකට ඒ repo එකට access නෑ. Step 1 එකේ inviteaura-builder tick කරලා තියෙනවද බලන්න.
  • 403 Forbidden → Contents: Read and write දීලා නෑ. Token එක edit කරලා Contents එක Read and write කරන්න, නැත්තම් අලුත් එකක් හදන්න. ("Contents" හොයාගන්න බෑ නම් Step 1 එකේ Option B — Classic token එකක් හදන්න.)
  • "Contents" permission එක හොයාගන්න බෑ → Repository permissions expand කරලා ලැයිස්තුවේ උඩට scroll කරන්න — Actions → Administration → Code quality → Contents. ඔයා දැක්ක Repository creation / license policy තියෙන්නේ ඒ ලැයිස්තුවේ පහළයි. තවම බෑ නම් Option B (Classic token) එක භාවිතා කරන්න.
  • Token එකක් නැතිව Save ඔබනවා → JSON file එක download වෙනවා. GitHub repo එකේ weddings folder එකට upload කළොත් live වෙනවා (manual විදිය).
  • 🔒 ආරක්ෂාව: Token එක කාටවත් share කරන්න එපා. ඕනෑ වෙලාවක GitHub Settings → token එක Delete කරන්න පුළුවන්.
